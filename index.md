Un libro para aprender R viendo cómo piensa cada programa: línea a línea, con la memoria a la vista. Es el hermano del libro de Python de la colección, y está hecho con el mismo método. Cada idea parte de una situación cotidiana, se construye con código y se comprueba visualizando la ejecución.

## Un libro, dos rutas

Como los programas del IB con su nivel medio y su nivel superior, este libro tiene **dos rutas** que conviven en las mismas páginas.

- La **ruta base** es la que sigue todo el mundo: la idea con un ejemplo hecho, el código visualizado paso a paso y los ejercicios. Sirve para clase y para aprender solo.
- Los apartados **A fondo** llevan una cápsula negra. Cuentan cómo funciona R por dentro y cómo se trabaja con él como profesional. Se pueden saltar sin perder el hilo.
